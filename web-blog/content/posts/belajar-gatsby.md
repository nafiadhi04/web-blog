# Belajar Gatsby.js untuk Pemula

Gatsby.js adalah framework berbasis React yang dapat digunakan untuk membuat website yang cepat dan modern.

Gatsby memiliki sistem GraphQL yang memungkinkan kita mengambil data dari berbagai sumber.

## Mengapa menggunakan Gatsby?

Beberapa kelebihan Gatsby antara lain:

- Berbasis React
- Mendukung static site generation
- Memiliki sistem GraphQL
- Mendukung berbagai sumber data
- Cocok untuk website blog dan dokumentasi

## Gatsby dan Markdown

Dalam project ini kita menggunakan Markdown sebagai sumber artikel.

File Markdown dibaca menggunakan `gatsby-source-filesystem`, kemudian diproses menggunakan `gatsby-transformer-remark`.

Dengan pendekatan tersebut kita dapat menulis artikel tanpa harus membuat halaman React secara manual.

## Kesimpulan

Gatsby merupakan salah satu framework React yang menarik untuk dipelajari, terutama jika ingin membuat website yang cepat dan terstruktur.
