# Mini Blog dengan Gatsby.js
Website blog sederhana yang cepat dan responsif menggunakan teknologi **Static Site Generation (SSG)**. Project ini dibangun menggunakan **Gatsby.js** dan **React.js**, di mana semua konten artikel diambil secara dinamis dari file Markdown.
🔗 **Live Demo:** [Lihat Website di Sini](https://lustrous-beignet-be1d41.netlify.app/) 
## 🛠️ Teknologi yang Digunakan
- **Framework:** Gatsby.js
- **UI Library:** React.js
- **Konten Data:** Markdown & GraphQL
- **Styling:** CSS Modules
